Download DevTrack

Install the latest stable release. The installers select your platform and fetch the published binary from GitHub Releases.

macOS and Linux

curl -fsSL https://mogrov.com/downloads/devtrack/install.sh | sh

Windows PowerShell

irm https://mogrov.com/downloads/devtrack/install.ps1 | iex

Review the shell script or PowerShell script before running it.

After installation, run devtrack version and devtrack setup. See the documentation for platform details and manual installation.
